# ASP.NET Core MVC Student Registration System

A Student Registration Web Application built using ASP.NET Core MVC, Entity Framework Core, SQL Server, and Identity Authentication.

## Features

- Student Registration
- Course Management (CRUD)
- Entity Framework Core
- SQL Server Database
- ASP.NET Core MVC
- Identity Authentication
- Responsive Bootstrap UI

## Technologies Used

- ASP.NET Core MVC
- C#
- Entity Framework Core
- SQL Server
- Bootstrap 5
- Visual Studio 2026
